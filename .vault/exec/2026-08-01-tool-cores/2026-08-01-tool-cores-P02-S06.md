# Enable Codex web search through the per-run config home in live mode as the served posture, gated on the proven set, with cached mode reachable by configuration for a deployment that prefers zero egress

## Description

- Declare the four documented web-search postures as protocol vocabulary and
  name live as the served one.
- Resolve the effective posture from the lane's web-proof verdict and the
  deployment preference, asymmetrically: an unproven lane resolves to disabled
  however the deployment configured it, and the preference applies only above
  the gate.
- Thread the resolved posture through the per-run configuration renderer and its
  builder as a REQUIRED keyword.
- Bind the resolver to the lane predicate at the model's config-home build.
- Add the deployment preference as one additive settings field.

## Outcome

The lane is wired to the gate rather than merely capable of being wired. With
the web declaration empty, every resolution yields disabled, so the capability
is dark exactly as the Phase requires.

Two live-verified facts changed the implementation and one of them corrected
this feature's own research. The posture key is a TOP-LEVEL key, not the
feature-table entry the published documentation describes: the executor checked
the installed binary rather than trusting the record, found both feature-table
forms deprecated, and elicited the parser's own error naming the four accepted
values. The structural consequence is the load-bearing half - a bare key placed
after a table header belongs to that table, so the posture must be emitted
before any declared-server block or the file parses cleanly and means something
else. That ordering is pinned by a test that parses the generated file rather
than one asserting on rendered text.

The posture is emitted unconditionally, including disabled, because the tool
enables web search by default. Absence meaning off would have been an
assumption; absence meaning on is the documented behaviour, so a config omitting
the key ships reach nobody admitted. This required rewriting an existing
assertion that an empty render produces an empty document, which was encoding
the older truth.

Acceptance drives the real installed binary over a production-built
configuration, and its control is what makes that mean anything: the same
rendered document with only the posture token substituted, proving the binary
exits non-zero naming all four variants. Without the control, a clean exit would
prove the file was tolerated rather than understood.

## Notes

The required keyword is a deliberate reversal, made after the executor reviewed
its own earlier claim and found it false. It had reported that the seam tests
proved the gate binding; they did not. With the declaration empty every
resolution yields disabled, which is exactly what a defaulted argument would
have produced, so deleting the entire binding from the production model would
have left the suite green. Removing the default converts that from something a
test might notice into something the interpreter refuses to run, matching the
unsafe-by-omission rule the trust axes in the same package already follow. A
mutation run is the acceptance evidence for the wiring, not the file contents.

The enum was deliberately NOT placed in the settings module despite that file
being granted. Importing the provider package into configuration would create an
edge the providers package deliberately breaks with a lazy import, so the
vocabulary went to the shared enum module that configuration already imports.

Two findings were raised and neither was acted on here. Every run of this
provider already emits a refusal to create helper binaries, because the per-run
home sits under the operating-system temporary tree. And the tool's debug
prompt-input output is byte-identical across all four postures, because search
is server-side and never reaches the model-visible prompt - which removes the
cheapest activation probe available and has been recorded against the live-proof
Step so nobody rediscovers it there.

This Step also spanned a feature-branch merge whose manual resolution dropped
this provider's authoring attach surface entirely while keeping the tests that
call it. The executor found it, refused to restore another branch's dropped
feature without authority, and restored it on instruction. It was invisible to
the type checker because the consumer reaches the method dynamically.
