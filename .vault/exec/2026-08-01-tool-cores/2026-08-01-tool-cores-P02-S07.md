# Compose the persona web-capability text lane-conditionally: the web-grounding paragraph with its citation obligations is injected for every document-authoring role only on lanes in the proven set, the existing no-online-access disclaimer stays the default, and preset descriptions remain unchanged in this Phase

## Description

- Compose the web-capability paragraph at the prompt-assembly seam, conditional
  on the lane's web proof rather than baked into preset text.
- Delete the persona's references to a fictional server's tools rather than
  gating them.
- Add a guard listing the tool names no persona may contain.

## Outcome

Personas claim web reach only on a lane that has earned the claim, and with the
proven declaration empty every persona keeps its disclaimer today.

This Step turned out to be a repair rather than an addition. The researcher
persona was instructing agents, by exact tool name and five times over, to call
tools of a server no shipped preset declares and none could - the model was told
to reach for something the harness never mounts, and would have improvised
rather than reported its grounding absent. That is a capability claim without
proof, which the project's own served-profile rule forbids one layer up.

The correct repair was deletion rather than gating, and the distinction matters:
gating a claim about something that does not exist would have preserved the
falsehood behind a condition. My earlier instruction said gate; it was wrong and
was corrected mid-Step.

The most durable artifact is the guard rather than the composition. A test now
lists the tool names no persona may contain - the two command-line built-ins,
because naming one lane's pair asserts one lane's shape as universal, and the
fictional server's name so it can never return through prose. The original
defect was precisely that: a persona hard-coded one lane's tool names as though
they were universal, and those names were not even real.

## Notes

The persona text describes the capability in terms of citation and disclosure
obligations rather than tool names, which is what makes it true across lanes
whose tools differ. That constraint came out of the defect rather than from the
row: any text naming specific tools would have been false on some lane, and was.

The proven declaration governs what a persona ASSERTS, never whether a lane can
search. An owner directive during this Phase made web reach universal, so text
reading unproven-means-no-access would encode the wrong contract; unproven means
not yet demonstrated.

The executing agent reached its session limit mid-flight, so this record is
written from the committed tree and the passing acceptance suite rather than its
report. The composition and the guard are verified present; what is not verified
in its own words is whether it considered and rejected any alternative to
deleting the fictional references outright.
